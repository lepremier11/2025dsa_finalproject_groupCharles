# 2025dsa_finalproject_groupCharles
Final Project – Repeated measure analysis 
Overview
This repository contains the data analysis, code, and results for my final project in CRSS. The goal of this project is to investigate how different soil amendments impact the survival of Escherichia coli over time across various field locations.

Project Goals
Analyze the effect of soil amendment type on E. coli populations.

Evaluate how sampling day and field location interact with amendment type.

Generate statistical models and plots to interpret the significance of these factors.

Present results in a clear and reproducible format.
PS: This dataset is the property of the University of Georgia and the University of Florida.

Team Members

Contents
data/: Raw and processed data used in the analysis.

code/: R scripts and Quarto files for data analysis and visualization.

output/: Figures.

final_report-APPOLON.qmd: Main Quarto document compiling our results and interpretation.

README.md: This file.

How to Use
To reproduce the analysis:

Open the final_report-APPOLON.qmd file in RStudio.

Ensure required packages are installed (nlme, emmeans, ggplot2, viridis, multcompView, etc.).

Knit the document to generate the final report.

Notes
All figures were saved with high resolution for clarity.

Statistical significance was assessed at α = 0.05.

CLDs (Compact Letter Displays) were used to represent pairwise group differences.
